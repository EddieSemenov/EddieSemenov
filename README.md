# Hi, I'm Eddie 👋

### Mechanical engineer building towards physical AI

MEng Mechanical Engineering graduate, working as a design engineer in London. Outside work I build robots that sense and act in the real world, and I'm working my way into physical AI: simulation, ROS 2, tactile sensing and learned control on real hardware.

I like owning the whole loop, from CAD and 3D printing through electronics and control to code running on a working prototype.

- 🦾 Building a **PAROL6 6-axis arm**, controlled from my own software and twinned in **NVIDIA Isaac Sim**
- 🖐️ Designing a **magnetic tactile end effector** so the arm can feel slip and friction
- 🏭 Interested in **manufacturing automation**, especially for SMEs that can't afford a systems integrator
- 🎥 Occasionally building things because they're funny, unnecessary, or both
- ⚡ Fun fact: I squat so I have a bigger cushion when I sit at my desk

## 🚀 What I'm building

**PAROL6 + Isaac Sim** *(active)*
Built and printed a [PAROL6 desktop arm](https://github.com/EddieSemenov/PAROL6-Desktop-robot-arm) and can drive it under my own control. Running a digital twin in Isaac Sim with a ROS 2 (Jazzy) action graph, plus a Python UI for joint control. Next up: an eFlesh-style magnetic tactile gripper for slip detection, designed in sim and heading for real-world testing.

**[eddiesemenov.com](https://eddiesemenov.com)** *(beta)*
My portfolio, built as an interactive 3D workshop. There's a robot arm you can play with and a nut you can throw around. Next.js on Vercel.

**[Finger Gun](https://github.com/EddieSemenov/Finger-Gun)**
Hand-tracked game in Python and MediaPipe. Point, flex your thumb, "pew".

**Kickstart Global PROBLEM Day** *(hackathon, Oct 2026)*
Proposed and worked on a production OS for manufacturing SMEs: one place to map the whole pipeline, its critical lines and its blockers, on top of the systems they already run.

**Earlier work**
- 🌱 Self-growing pneumatic continuum robot for confined-space inspection (MEng)
- ✏️ Autonomous drawing robot with embedded C motion control on Arduino
- 📊 Production dashboard and backend database for a factory floor (Made Smarter internship)
